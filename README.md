# Portofolio HTML semantik

Buka `index.html` di browser (klik dua kali), atau di VS Code gunakan ekstensi Live Server.

Struktur:
  index.html        halaman
  css/style.css     gaya (palet ada di :root)
  js/script.js      interaksi
  images/           foto, sertifikat, logo
  ANALISIS.md       keputusan desain, kendala, cara debugging
